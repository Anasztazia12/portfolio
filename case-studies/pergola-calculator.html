Client project

Pergola Calculator

A 3D configurator for a construction company: change the design and see the materials and the price straight away.

  • My roleDesign and development
  • ClientConstruction company, Hungary
  • StackJavaScript, Babylon.js, Firebase
Live site

The problem

For every pergola job the company worked out the concrete, timber and screw quantities by hand, using spreadsheets. It was slow, and a mistake in the numbers meant ordering the wrong materials.

What I built

A web app where the customer sets the size, roof pitch, wood type and other options. The 3D model, the full material list and the price estimate update straight away, and the bill of materials can be downloaded.

Technical details

  • The 3D pergola is drawn in the browser with Babylon.js and changes as the settings change.
  • I turned the company's spreadsheet calculations into JavaScript functions.
  • The calculation runs in a Firebase Cloud Function on Node.js, not in the browser, so the company's formulas stay private.
  • Separate Cloud Functions handle cutting optimisation and plan generation.
  • Static files are served by Firebase Hosting, which forwards /api/calculate to the Cloud Function.

How a calculation works

  1. The browser sends the chosen settings to /api/calculate.
  2. The Cloud Function checks where the request comes from and applies a rate limit.
  3. It runs the formulas and signs the response with a secret key.
  4. The browser updates the 3D model, the material list and the price.

Challenges and fixes

Keeping the formulas private. In the browser anyone can read the JavaScript. I moved the calculation to a Cloud Function and only send the results back. The readable source of the browser code is kept privately and only an obfuscated build is published.

Moving off PHP hosting. The first version ran a PHP backend on cPanel. I moved the whole app to Firebase Hosting and Cloud Functions and deleted the old PHP files and .htaccess rules.

Secrets and local testing. The signing key is stored with Firebase secrets, never in the code. For local development I use the Firebase Emulator Suite, with the key in a local file that is never committed.
