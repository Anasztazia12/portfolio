03How I work

  1. PlanI write user stories and track them on a GitHub Project board, then split the scope into must have, should have and could have.
  2. DesignI sketch wireframes and plan the structure of each page before I start building.
  3. Model the dataI decide on the database models and their relationships early, because changing them later costs the most time.
  4. BuildI build in small steps and commit often, so every change is easy to follow and to undo.
  5. TestI write automated tests (Django TestCase, Jest), test by hand on desktop and phone, and validate HTML and CSS with the W3C validators.
  6. Deploy and documentI deploy to Heroku, Render or Firebase and write a README covering setup, testing and the bugs I found and fixed.
